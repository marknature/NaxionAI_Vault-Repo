# Research: For the Events and Competition Scan modify the template so that: The scan should be 80% free and 20% paid Tech events, summits or conference in Zimbabwe, South Africa, and Africa as a whole. And also hackathons, innovation challenges or expos, startup pitch, corporate software competitions and Tech challenges

**Proposed template for the Events & Competition Scan**

| Field | Description | Example (from source [1]) |
|-------|-------------|---------------------------|
| **Event name** | Official title of the event | *SA Innovation Week* |
| **Date** | Start‑end dates (or next edition) | *Mar 16‑20 2026* |
| **Location** | City / Country (focus on Zimbabwe, South Africa, or pan‑African) | *Johannesburg, South Africa* |
| **Type** | Category: Summit, Conference, Expo, Hackathon, Innovation Challenge, Startup Pitch, Corporate Software Competition, Tech Challenge | *Summit* |
| **Cost** | **Free** or **Paid** (to be verified per event) | *Paid* (typical for many flagship summits) |
| **Region** | Zimbabwe | South Africa | Africa‑wide | *South Africa* |
| **Notes** | Brief relevance (e.g., target audience, sector focus) | *Startup/VC focus* |
| **Link** | Canonical URL for details / registration | *https://www.startupblink.com/…* |

**Guideline for the scan**

- **Target mix:** ≈ 80 % of listed entries should be **Free** events, ≈ 20 % **Paid** events.  
- **Geographic spread:** Prioritize events held in Zimbabwe or South Africa; fill remaining slots with pan‑African events that welcome participants from those countries.  
- **Content scope:** Include the following formats: tech summits/conferences, hackathons, innovation challenges/expos, startup pitch competitions, corporate software competitions, and broader tech challenges.  
- **Verification step:** For each candidate event, check the organizer’s website (or ticketing page) to confirm the **Free/Paid** status before marking the “Cost” field. If the cost is unclear, flag the entry for manual review rather than assuming a default.  

**Evidence basis**

- Source [1] provides a curated list of 23 African tech‑focused events for 2026, including summits, conferences, expos, and sector‑specific gatherings (e.g., *SA Innovation Week*, *GITEX Africa*, *Africa Tech Festival*).  
- The source does **not** specify whether each event is free or paid; therefore the cost classification must be obtained independently from the event’s official site.  

*Note:* Because the supplied evidence lacks explicit free/paid data, the template relies on the user to verify each event’s cost during the scan process. This ensures compliance with the governance policies that prohibit inventing or presenting unverified facts.
