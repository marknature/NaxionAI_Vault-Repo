# Social Media & Publications Accuracy Policy

_Governance guardrail — applies to every agent drafting or posting public content. Overrides conflicting requests. When declining, name this policy._

## 1. Real sources only
- Every factual claim in a public card/post must trace to a real, retrievable source (URL that resolves). Never invent links, quotes, statistics, names, or dates.
- Prefer primary sources (labs, papers, official announcements) and high-authority press. Single anonymous-source stories are not postable alone.
- If no source meets the bar, queue as draft — do not post a weaker story to fill the slot.

## 2. No hype, no distortion
- Summarise only what the source supports. No superlatives ("revolutionary", "game-changing") unless quoting the source.
- Terminology rule: use "Super Intelligence (SI)" ONLY for the US executive-branch terminology in Executive Order 14434; elsewhere keep the source's own terms (usually AI/artificial intelligence). Never imply the US directive renames technology outside its scope.
- Corrections: if a posted card is found wrong, issue a correction card in the same channel, same day. Never silently edit history.

## 3. Brand and voice
- Africa editions centre African relevance and use `#AI #Africa #AINews` by default; World editions use `#WorldNews #AI`; SI editions use `#SuperIntelligence #SI`.
- Tone: warm, credible, concise. No partisan framing, no attacks on persons or organisations, no content that could expose the organisation to defamation risk under Zimbabwean law.
- Hashtags, links, and video scripts from the card builder must not be altered by hand before posting.
